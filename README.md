# 네이버 SA + GFA 통합 매출 성장 전략 제안서

기존 두 웹 제안서의 내용 흐름을 하나로 합치고, SA와 GFA 사이에 SA 성과 개선 레퍼런스 2페이지를 추가한 GitHub Pages용 패키지입니다.

## 페이지 구성
- SA 기존 10페이지
- 기존 SA 성과 개선/핵심 액션 2페이지
- SA 추가 레퍼런스 3페이지
- GFA 기존 10페이지
- GFA 추가 레퍼런스 3페이지
- 총 28페이지

## 추가 레퍼런스
1. 동일 광고비 기준 BEFORE / AFTER 성과 예시
2. 성과를 개선한 핵심 운영 액션 5가지

성과 수치가 포함된 레퍼런스 페이지에는 운영 구조 설명을 위한 예시 데이터라는 주석을 포함했습니다.

## GitHub Pages 적용
1. ZIP 압축 해제
2. 파일 전체를 GitHub Repository 최상위(root)에 업로드
3. Settings → Pages
4. Deploy from a branch
5. main / (root) 선택 후 Save
