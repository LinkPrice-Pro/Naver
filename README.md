# 네이버 SA + GFA 통합 매출 성장 전략 제안서

기존 두 웹 제안서의 내용 흐름을 하나로 합치고, SA와 GFA 사이에 가상 성과 개선 레퍼런스 2페이지를 추가한 GitHub Pages용 패키지입니다.

## 페이지 구성
- SA 10페이지
- 가상 성과 개선 레퍼런스 2페이지
- GFA 10페이지
- 총 22페이지

## 추가 레퍼런스
1. 동일 광고비 기준 BEFORE / AFTER 가상 성과
2. 성과를 개선한 핵심 운영 액션 5가지

가상 레퍼런스는 실제 광고주 실적이 아니며, 제안서 본문에도 가상 시뮬레이션임을 명확히 표기했습니다.

## GitHub Pages 적용
1. ZIP 압축 해제
2. 파일 전체를 GitHub Repository 최상위(root)에 업로드
3. Settings → Pages
4. Deploy from a branch
5. main / (root) 선택 후 Save
