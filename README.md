# 네이버 SA + GFA 통합 매출 성장 전략 제안서

기존 SA/GFA 제안서 내용은 유지하고, 불필요한 기존 11·12페이지를 삭제한 뒤 SA 레퍼런스 번호와 전체 목차 흐름을 자연스럽게 재정리한 GitHub Pages용 패키지입니다.

## 페이지 구성
- SA 기존 10페이지
- SA 레퍼런스 3페이지
  1. 키워드 구조 개선
  2. 상품 집중 운영
  3. 랜딩 전환 개선
- GFA 기존 10페이지
- GFA 레퍼런스 3페이지
  1. 신규 고객 확장
  2. 리타겟팅 세분화
  3. 소재 최적화
- 총 26페이지

## 변경 사항
- 기존 제안서 11페이지 삭제
- 기존 제안서 12페이지 삭제
- SA 레퍼런스 번호를 01 → 02 → 03으로 재정렬
- 목차와 하단 페이지 수는 실제 슬라이드 수 기준으로 자동 반영
- SA 본문 → SA 레퍼런스 → GFA 본문 → GFA 레퍼런스 순으로 자연스럽게 연결

## GitHub Pages 적용
1. ZIP 압축 해제
2. 파일 전체를 GitHub Repository 최상위(root)에 업로드
3. Settings → Pages
4. Deploy from a branch
5. main / (root) 선택 후 Save

## 조작
- 하단 ← → 또는 키보드 ← →
- 우측 상단 목차
- PDF 저장
- `#page-11` 형태로 특정 페이지 바로 열기

- 13페이지: 설명 문장 자연스러운 줄바꿈 적용
- 22페이지: GFA Before / After 성과 수치 레퍼런스 추가
